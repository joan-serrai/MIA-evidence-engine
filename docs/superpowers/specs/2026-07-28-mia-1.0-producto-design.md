# MIA 1.0 — "De demo a producto" · Diseño

## Contexto
MIA es un motor RAG biomédico 100% local (dermatitis atópica) con citas deterministas.
Está funcional end-to-end (5 fases). El objetivo de este trabajo es elevarlo de "demo de
curso" a **producto software creíble y vendible**, sin salirse de su línea principal
(local, soberano, con citas). Alcance aprobado por el usuario: A, B, C, D.

## Alcance
### A. Informe de evidencia exportable (feature estrella)
- `src/report.py`: `build_report_html(question, data) -> str` genera un HTML **autónomo**
  (CSS inline, imprimible → PDF con Ctrl+P) con marca MIA. Contiene: cabecera de marca +
  sello "100% local", pregunta y fecha/hora, respuesta con sus citas `[Doc N]`, tabla de
  "Datos clave" agrupada por paper (solo fuentes citadas), lista de fuentes citadas con
  enlace y % de confianza, apéndice de "también recuperadas (no citadas)" con su motivo,
  y pie "Generado localmente por MIA — sin nube".
- App: `st.download_button` por turno (clave estable = hash del texto) que descarga el HTML.

### B. UI de producto + panel de estado
- `src/status.py`: `system_status() -> dict` comprueba Ollama (`GET {OLLAMA_HOST}/api/tags`),
  presencia de los modelos de `config`, y nº de chunks del corpus (ChromaDB). Robusto: nunca
  lanza; devuelve flags + detalle.
- App (sidebar): sección "Estado del sistema" con semáforos (Ollama ✓/✗, modelos ✓/✗,
  corpus: N papers). Cacheado (`st.cache_data`, ttl 30s).
- App: galería de ejemplos por intención (Eficacia / Seguridad / Comparativa).

### C. Robustez / errores accionables
- Al arrancar: si Ollama caído / faltan modelos / corpus vacío → banner claro con el comando
  exacto para arreglarlo (no traceback).
- Generación de respuesta envuelta en try/except: error de conexión con Ollama → tarjeta de
  error amable con la solución, en vez de romper la app.

### D. Lanzador de un clic
- `run.ps1`: verifica `.venv`, comprueba Ollama (avisa si no está), y lanza Streamlit abriendo
  el navegador. Mensajes claros.
- `run.bat`: envoltorio de doble clic que llama a `run.ps1`.

## Fuera de alcance (a propósito)
- Multi-enfermedad **en caliente**: el índice es específico de dermatitis atópica; cambiarlo
  en runtime sin re-ingesta sería deshonesto. Queda como plantilla configurable documentada.

## Criterio de éxito
La app parece un producto comercial; se puede preguntar y **descargar un informe con citas
presentable**; arranca con doble clic sin errores crípticos; si algo falta, lo dice con la
solución. Verificable con: `py_compile`, `AppTest` (sin excepciones), chequeo real de
`system_status()`, y generación real de un informe HTML válido.
