# MIA · Medical Intelligence Agent

**A local, sovereign evidence engine for biomedical literature.**
Ask a question about a disease and its drugs; MIA answers from the abstracts and trial
records it has indexed on your computer, citing the exact source of every statement.
Nothing you type ever leaves your machine: the search, the language model and the
database all run locally.

> **Experimental.** MIA is a research prototype, not a medical device. Answers are
> drafted by a small local language model from the abstracts it retrieved and can be
> incomplete or wrong. Always read the cited sources before using any figure, and never
> base a clinical decision on MIA alone.

---

## What it does

1. **Retrieve.** Your question is embedded with [MedCPT](https://huggingface.co/ncbi/MedCPT-Query-Encoder),
   a biomedical model trained by the NCBI on 255 million PubMed query–article pairs, and
   matched against your local corpus (PubMed abstracts and ClinicalTrials.gov records,
   including posted results).
2. **Gate.** If the best match is below the evidence threshold, MIA does **not** answer
   from memory. It says so, or hands over to the **Scout agent**, which searches PubMed and
   ClinicalTrials.gov, imports what it finds, indexes it and retries.
3. **Answer and cite.** A local biomedical LLM (OpenBioLLM 8B, through Ollama) writes the
   answer using only the retrieved text. The `[Doc N]` citations are then placed and
   validated **deterministically**, sentence by sentence: no citation can point to a source
   that does not exist.
4. **Figures.** Numbers in the chart (response rates, adverse-event rates) are extracted from
   the abstracts with fixed rules, never generated by the model.

You choose the disease. MIA ships with **no corpus**: the first time you open it, the
*Build corpus* tab asks for a disease, suggests the most studied drugs from
ClinicalTrials.gov, and downloads and indexes the evidence for you. Profiles are saved on
your computer and you can keep several (one per disease).

## Requirements

- **Windows 10/11** (the guided installer is PowerShell; see *Manual install* for other systems).
- **Python 3.12** — https://www.python.org/downloads/ (tick *"Add python.exe to PATH"*).
- **Ollama** — https://ollama.com/download (next, next; it stays in the system tray).
- About **7.5 GB** of disk: Python libraries (1.6 GB), the OpenBioLLM 8B model (4.9 GB) and
  the MedCPT encoders (0.8 GB). A GPU is not required, but answers are much faster with one.
- Internet access to build a corpus (PubMed and ClinicalTrials.gov public APIs). Asking
  questions works offline.

## Install (guided, ~30 min)

1. Download the code: green **Code** button → **Download ZIP**, unzip to a **short path** such
   as `C:\dev\MIA` (Windows limits paths to 260 characters and the Python libraries nest deeply).
   Or `git clone` it.
2. Install Python and Ollama (links above) if you do not have them.
3. Double-click **`setup.bat`**. A terminal window walks you through 8 steps and **asks before
   every large download**, telling you what it is and where it goes:

   | Step | What it does | Download |
   |------|--------------|----------|
   | 1–2 | Finds Python and creates the virtual environment `.venv` | — |
   | 3 | Installs the pinned dependencies (`requirements.lock.txt`) | 1.6 GB |
   | 4 | Creates an empty `.env` from `.env.example` (nothing to fill in) | — |
   | 5 | Checks that Ollama responds (starts it if installed but stopped) | — |
   | 6 | Downloads the biomedical model with `ollama pull` | 4.9 GB |
   | 7 | Downloads the MedCPT encoders from HuggingFace | 0.8 GB |
   | 8 | Reports that the corpus is empty: you build it in the app | 0 |

   If Python or Ollama is missing the script says so, gives the link and stops; run it again
   and it continues where it left off. It can be run as many times as you like: what is
   already done shows `[OK]`.

   > The first time, Windows may show *"Windows protected your PC"* because the script is not
   > signed: click *More info → Run anyway*.

4. Double-click **`run.bat`**. MIA opens in your browser at http://localhost:8501.

### Manual install (same steps by hand)

```powershell
ollama pull koesn/llama3-openbiollm-8b:q4_K_M
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
copy .env.example .env
.\.venv\Scripts\python.exe check_setup.py
.\.venv\Scripts\python.exe -m streamlit run app/streamlit_app.py
```

On Linux/macOS use `python3 -m venv .venv` and `.venv/bin/python`; the code is plain Python,
but it has only been tested on Windows.

## First use: build your corpus

MIA opens on the **Build corpus** tab while it has no corpus.

1. Type the disease (for example `Plaque psoriasis`) and, optionally, synonyms.
2. Press **Suggest drugs**: MIA counts trials on ClinicalTrials.gov and lists the most
   studied drugs for that disease. Pick the ones you care about (or type your own).
3. Optionally add mechanisms (`il-17=secukinumab,ixekizumab`), efficacy endpoints
   (`PASI 75`) and extra searches.
4. Choose the coverage. *Standard* (100 documents per drug and source) takes 10–30 minutes;
   *no cap* can take hours and gigabytes, and the app warns you.
5. Press **Build**. The download and indexing run in the background and you see the log live.

When it finishes, the profile becomes active, the **MIA** tab moves to the front and example
questions for that disease appear. Questions must be in **English** (the corpus and the model
are). Try: *"What is the efficacy of secukinumab in plaque psoriasis?"*

The same thing from a terminal:

```powershell
.\.venv\Scripts\python.exe suggest_drugs.py --disease "Plaque psoriasis" --top 10 --phase3
.\.venv\Scripts\python.exe build_corpus.py --disease "Plaque psoriasis" --synonym psoriasis --class "il17_biologics=secukinumab,ixekizumab" --endpoint "PASI 75" --max 100 --activate
.\.venv\Scripts\python.exe src\rag.py "What is the efficacy of secukinumab in plaque psoriasis?"
```

An example profile is included in `domains/examples/atopic_dermatitis.json`. Copy it to
`domains/` and run `run_phase1.py --domain atopic_dermatitis` to download that corpus.

## What you get with every answer

- The answer with **highlighted citations** `[Doc N]`, each linked to its source card
  (title, PubMed or ClinicalTrials.gov link, drugs, open access or abstract-only).
- A **figures chart** with the response and adverse-event rates found in the sources, each
  traceable to its document.
- **Related reading**: papers that passed the evidence gate but were not used in the answer.
- **Retrieval details**: what was retrieved, its similarity score and whether the Scout ran.
- A downloadable **evidence report** (self-contained HTML, printable to PDF).

---

## Privacy

- No telemetry, no accounts, no server. Streamlit's usage statistics are switched off and
  the app listens on `localhost` only.
- The only network calls are to PubMed and ClinicalTrials.gov when you build a corpus or the
  Scout runs, and to HuggingFace and Ollama once, to download the models.
- An optional NCBI API key in `.env` raises PubMed's rate limit; it is never required.

## Known limits

- Questions must be in English.
- MIA reads **abstracts and trial records**, not full papers or PDFs.
- The evidence threshold was calibrated on atopic dermatitis; it behaved well on psoriasis
  and retinoblastoma, but check it on very different domains.
- With small corpora, sentence-level citations can be missing when all sources say the
  same thing.
- The Windows installer is the only tested install path.
