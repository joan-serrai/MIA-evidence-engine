# ─────────────────────────────────────────────────────────────────────────────
# ¿POR QUÉ LAS VERSIONES ESTÁN FIJADAS CON "==" Y NO CON ">=" ?
# ─────────────────────────────────────────────────────────────────────────────
# Hasta el 31-ago-2026 este archivo usaba ">=" (p. ej. "chromadb>=0.5"), que
# significa "esa versión o cualquiera posterior". Suena flexible, pero al montar
# el proyecto en un ordenador nuevo pip instaló las últimas de todo, y llegaron
# saltos de versión MAYOR respecto a las originales:
#
#     transformers  4.x  →  5.16     pandas  2.x  →  3.0
#     numpy         1.x  →  2.5      torch   2.x  →  2.13
#
# Un salto de versión mayor puede romper la API sin previo aviso. Esta vez todo
# funcionó (se verificó ejecutando el pipeline entero), pero fue SUERTE, no
# diseño. Con "==" congelamos exactamente lo que sabemos que funciona: el
# proyecto se reinstala igual dentro de un año, en otro equipo o para el
# tribunal del TFM.
#
# ¿Y para actualizar? A propósito, a mano: se sube una dependencia, se prueba,
# y si va bien se fija la nueva versión aquí. Nunca por accidente.
#
# Estas versiones están VERIFICADAS en Windows 11 + Python 3.12.10 (31-ago-2026):
# corpus de 8.920 chunks recuperado con MedCPT, RAG completo con OpenBioLLM,
# ambas páginas de Streamlit y las evaluaciones de embeddings.
#
# NOTA: aquí solo van las dependencias DIRECTAS (las que importa nuestro código).
# El árbol completo, con las 122 librerías del entorno, está en
# `requirements.lock.txt` — úsalo si necesitas reproducir el entorno EXACTO.
